# Biblical Hebrew Adapter Fixture

This occurrence fixture uses vocalized forms from Open Scriptures Hebrew
Lexicon `HebrewStrong.xml` at commit
`21c9add13bc727d3a951361778e97e3ff7afd1ce`, licensed CC BY 4.0: H215/H216
(`אוֹר`), H517 (`אֵם`), H4430 (Aramaic `מֶלֶךְ`), and H7121/H7122
(`קָרָא`). The `בְּרֵאשִׁית` occurrence and all occurrence counts are synthetic.

It contains no BHSA text or ETCBC phono records and is not claimed to be
equivalent to BHSA. IPA readings are synthetic test inputs chosen solely to
exercise the normalization boundary.
